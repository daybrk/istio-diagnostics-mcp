# istio-diagnostics-mcp

Проект MCP-сервера на Go для диагностики связности приложений в Kubernetes/Istio.

**Состояние этой ветки: чистая основа для реализации по спецификации.** Старый
прототип удалён из рабочего дерева. Запускаемого MCP-сервера и Docker-образа здесь
пока нет; CI проверяет проектные контракты и инструкции.

## Проектный комплект

Начать с [оглавления](docs/design/README.md).

Целевой режим — live read-only, sidecar, east-west cluster-local. Сервер работает
снаружи кластера по kubeconfig, получает логи `istio-proxy` и читает Envoy через
временный port-forward на 15000. Поддерживаются все доступные реплики и выбранный
пользователем период. Собственная LLM серверу не требуется.

## Проверка артефактов

Требуется Go 1.25+:

```bash
go run -mod=readonly docs/design/validate_contracts.go
```

Проверяются схемы, примеры запросов/ответов, конфигурация, manifest промптов и
внутренние ссылки. Это не проверка реализованного сервера или реального кластера.
Единственная текущая Go-зависимость нужна проверке JSON Schema. Зависимости
будущего сервера будут добавляться вместе с реализацией.

## Архив прототипа

Полная прежняя реализация, её тесты, примеры и конфигурации сохранены в
[ветке archive/go-mcp-v0.1](https://github.com/daybrk/istio-diagnostics-mcp/tree/archive/go-mcp-v0.1),
commit `832578f9f23a44355841fe974a5e89167c6fce6e`.

Работа продолжается в исходной ветке `feat/go-mcp-v0.1`. Обратная совместимость
со старыми публичными tools не требуется. Отдельные правила и тестовые сценарии
можно переносить из архива после проверки соответствия новой спецификации.
